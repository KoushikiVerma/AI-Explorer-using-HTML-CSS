Machine Learning

What is it:-

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that allows computers to learn from experience (data) and make smart decisions without being explicitly programmed. Instead of following fixed rules, ML models recognize patterns, improve over time, and become better at tasks—just like how humans learn from experience!

Different Types of Machine Learning:

1️⃣ Supervised Learning – Learning from Examples
In this type, the model is trained on labeled data (where the correct answers are already known). Think of it like a student learning with a teacher’s guidance.
🔹 Example: Spam detection—where emails are already marked as spam or not spam.
🔹 Common Algorithms: Linear Regression, Decision Trees, Random Forest, Neural Networks

2️⃣ Unsupervised Learning – Finding Hidden Patterns
Here, the model doesn’t have labeled data—it figures out patterns on its own, much like a baby learning to recognize different objects without being told what they are.
🔹 Example: Customer segmentation—grouping shoppers based on buying habits without knowing their preferences beforehand.
🔹 Common Algorithms: K-Means Clustering, Principal Component Analysis (PCA), Autoencoders

3️⃣ Reinforcement Learning – Learning by Trial and Error
This works just like how we learn from mistakes and rewards in real life. The model interacts with an environment, makes decisions, and gets rewarded for good actions or penalized for bad ones.
🔹 Example: Self-driving cars—learning to drive safely by adjusting speed, turning, and braking based on real-time feedback.
🔹 Common Algorithms: Q-Learning, Deep Q Networks (DQN), Proximal Policy Optimization (PPO)

Machine Learning Terminologies:-

  • Accuracy - The percentage of correctly predicted outcomes in a classification model.
  • Activation Function - A function in neural networks that determines the output of a node (e.g., ReLU, Sigmoid).
  • Algorithm - A set of rules or steps used to train ML models.
  • Anomaly Detection - Identifying rare or unusual patterns in data.
  • Artificial Neural Network (ANN) - A computational model inspired by the human brain for pattern recognition.
  • Autoencoder - A neural network used for unsupervised learning and feature extraction.
  • AUC-ROC (Area Under Curve - Receiver Operating Characteristic) – A metric for evaluating classification models.
  • Backpropagation - A method used in neural networks to adjust weights based on error calculation.
  • Bagging (Bootstrap Aggregating) - An ensemble method that combines multiple models for improved accuracy.
  • Batch Gradient Descent - A training method where the entire dataset is used to update model parameters.
  • Batch Size - The number of training samples processed before updating model parameters.
  • Bias - The error introduced due to incorrect assumptions in a model.
  • Bias-Variance Tradeoff - The balance between underfitting (high bias) and overfitting (high variance).
  • Boosting - An ensemble technique that combines multiple weak learners to form a strong model.
  • Bootstrap Sampling - A resampling technique used in ensemble learning methods like bagging.
  • Categorical Data - Data divided into distinct categories (e.g., colors, types).
  • Classification - A type of ML where the model assigns input data to predefined labels.
  • Clustering - An unsupervised ML technique that groups similar data points.
  • Confusion Matrix - A table used to measure classification model performance (e.g., True Positive, False Positive).
  • Convolutional Neural Network (CNN) - A type of deep learning model used for image recognition.
  • Cost Function - A function that measures the error of a model’s predictions.
  • Cross-Entropy Loss - A loss function commonly used in classification problems.
  • Cross-Validation - A method to evaluate a model by training and testing it on different subsets of data.
  • Curse of Dimensionality - The challenge of dealing with high-dimensional data that affects model performance.
  • Data Augmentation - A technique that increases training data by making modifications like rotation or flipping.
  • Data Cleaning - The process of removing or fixing incorrect, inconsistent, or missing data.
  • Data Preprocessing - Transforming raw data into a suitable format for ML models.
  • Data Splitting - Dividing data into training, validation, and test sets.
  • Decision Tree - A supervised learning algorithm that splits data into branches for prediction.
  • Dimensionality Reduction - Techniques like PCA used to reduce the number of features in a dataset.
  • Early Stopping - A method to prevent overfitting by stopping training when performance plateaus.
  • Embedding - A way to represent categorical variables or text as continuous-valued vectors.
  • Ensemble Learning - A method that combines multiple models to improve predictions.
  • Epoch - One complete pass of the dataset through the training algorithm.
  • Exploratory Data Analysis (EDA) - The process of visualizing and summarizing data before training a model.
  • False Negative (FN) - A case where a model incorrectly predicts a negative outcome instead of a positive one.
  • False Positive (FP) - A case where a model incorrectly predicts a positive outcome instead of a negative one.
  • Feature Engineering - The process of creating new features to improve model performance.
  • Feature Importance - A measure of how much a feature contributes to the model’s prediction.
  • Feature Scaling - Normalizing data to bring all features to a similar scale.
  • Federated Learning - A decentralized ML approach where models train across multiple devices without sharing raw data.
  • Generalization - The ability of an ML model to perform well on unseen data.
  • Gradient Descent - An optimization algorithm used to minimize the loss function by adjusting model parameters.
  • Graph Neural Network (GNN) - A deep learning model designed to work with graph-structured data.
  • Hidden Layer - Layers of neurons in a neural network between the input and output layers.
  • Hyperparameter - A configuration setting that controls the training process but is not learned from data.
  • Hyperparameter Tuning - The process of optimizing hyperparameters to improve model performance.
  • Imbalanced Data - A dataset where one class is significantly more represented than another.
  • Inference - The process of using a trained model to make predictions.
  • Instance-Based Learning - A method where predictions are based on previously seen examples rather than generalization.
  • K-Fold Cross Validation - A method to split data into multiple folds for training and testing.
  • K-Means Clustering - An unsupervised learning algorithm that groups data into clusters.
  • Kernel Trick - A method used in Support Vector Machines (SVM) to transform data into a higher-dimensional space.
  • Label - The output variable a supervised learning model is trying to predict.
  • Latent Variable - A hidden variable inferred from observable data.
  • Learning Rate - A hyperparameter that controls how much the model updates weights during training.
  • Logistic Regression - A classification algorithm used for binary classification problems.
  • Loss Function - A function that quantifies the difference between predicted and actual values.
  • Mean Squared Error (MSE) - A loss function commonly used in regression problems.
  • Mini-Batch Gradient Descent - A variation of gradient descent that updates weights using small data batches.
  • Model Drift - The decline in model accuracy over time due to changing data patterns.
  • Multi-Class Classification - A classification problem with more than two possible output categories.
  • Naïve Bayes - A probabilistic classification algorithm based on Bayes' theorem.
  • Neural Network - A machine learning model inspired by the structure of the human brain.
  • Normalization - A technique used to scale numerical values to a standard range.
  • One-Hot Encoding - A method to convert categorical variables into numerical format.
  • Overfitting - A situation where a model learns patterns from training data too well and performs poorly on new data.
  • Precision & Recall - Metrics used to evaluate classification models.
  • Principal Component Analysis (PCA) - A dimensionality reduction technique used to simplify data.
  • Pruning - The process of removing unnecessary nodes in decision trees or neural networks to improve efficiency.
  • Recurrent Neural Network (RNN) - A deep learning model designed for sequential data, such as time series or text.
  • Regularization - A technique used to prevent overfitting by adding a penalty to the loss function.
  • Reinforcement Learning (RL) - A learning approach where an agent learns by interacting with an environment and receiving rewards.
  • Support Vector Machine (SVM) - A classification algorithm that finds the best hyperplane for separating data points.
  • Stochastic Gradient Descent (SGD) - A variation of gradient descent that updates weights using only one sample at a time.
  • Transfer Learning - Using a pre-trained model for a new but related task.
  • Tuning - The process of adjusting hyperparameters for better performance.
  • Underfitting - When a model is too simple and fails to capture patterns in data, leading to poor performance.
  • Unsupervised Learning - A type of ML where models find patterns in data without labeled outputs.
  • Upsampling - A technique used to increase the representation of minority classes in imbalanced datasets.
  • U-Net - A convolutional neural network architecture commonly used for image segmentation.
  • Validation Set - A dataset used during model training to tune hyperparameters and avoid overfitting.
  • Vanishing Gradient Problem - A challenge in deep learning where gradients become too small, slowing down learning in deep networks.
  • Variance - A measure of how much a model’s predictions change when trained on different datasets.
  • Variational Autoencoder (VAE) - A generative model used for learning latent representations of data.
  • Vectorization - The process of converting data (e.g., text or images) into numerical format for machine learning models.
  • Weight Decay - A regularization technique that penalizes large model weights to prevent overfitting.
  • Weight Initialization - The method of assigning initial values to neural network weights before training.
  • Word Embeddings - Representations of words in a continuous vector space, used in NLP (e.g., Word2Vec, GloVe).
  • Weak Learner - A model that performs slightly better than random guessing but can be combined into a strong learner using ensemble methods like boosting.
  • XGBoost (Extreme Gradient Boosting) - A powerful gradient boosting algorithm widely used in ML competitions and real-world applications.
  • XOR Problem - A classical problem in ML that highlights the limitations of simple perceptrons in solving non-linear problems.
  • Y-Label (Target Variable) - The output variable that a supervised learning model aims to predict.
  • YOLO (You Only Look Once) - A deep learning algorithm for real-time object detection.
  • Zero-Shot Learning (ZSL) - A learning paradigm where a model can recognize new classes without having seen examples of them during training.
  • Z-Score Normalization - A feature scaling method that transforms data based on mean and standard deviation.
