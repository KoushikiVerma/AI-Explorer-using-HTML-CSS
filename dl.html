Deep Learning

What is it :-

Deep Learning is a subset of Machine Learning that focuses on training artificial neural networks with multiple layers. These layers help computers process and understand data in ways similar to the human brain. The more layers a neural network has, the more complex patterns it can learn, which is why Deep Learning is often used in advanced AI applications like self-driving cars, speech recognition, image processing, and even medical diagnosis.

Deep Learning Terminologies:-

  • Neural Network- A system of interconnected neurons (like the human brain) that processes data.
  • Forward Propogation-The process where input data flows through a neural network to produce an output.
  • Back Propogation-A method used to adjust the weights of a neural network based on errors, improving accuracy.
  • Activation Function-Determines whether a neuron should be activated (e.g., ReLU, Sigmoid, Softmax).
  • Weights & Biases-Values that are adjusted during training to optimize the model’s performance.
  • Loss Function- Measures how well a model is performing (lower loss = better performance).
  • Optimization Algorithm-A technique used to adjust weights efficiently (e.g., Gradient Descent, Adam).
  • Epoch-One complete pass over the training dataset.
  • Batch Size-The number of samples processed before updating the model’s weights.
  • Overfitting-The model learns too well from training data, failing on new data.
  • Underfitting- The model is too simple and doesn’t learn patterns effectively.
  • Convolutional Neural Networks (CNNs)-sed mainly for image processing (e.g., object detection, facial recognition).
  • Recurrent Neural Networks(RNNs)- Used for sequential data like speech recognition, time series prediction, and chatbots.
  • Transformer Models-Advanced AI architectures (e.g., GPT, BERT) used in NLP tasks.
