Generative AI

What is it:-

AI that can write stories, create art, compose music, design graphics, or even generate code—all from scratch! That’s the power of Generative AI. Instead of just analyzing or recognizing data, these models generate new content based on what they’ve learned.
Generative AI powers applications like:
✅ AI Chatbots (e.g., ChatGPT, Google Bard)
✅ AI Art & Image Generation (e.g., MidJourney, DALL·E)
✅ Music Composition (e.g., Jukebox by OpenAI)
✅ Code Generation (e.g., GitHub Copilot)
✅ Synthetic Video & Deepfakes (e.g., Sora, DeepFaceLab)

Generative AI Terminologies:-

  • Transformer Models- Deep learning models that generate content based on patterns in large datasets (e.g., GPT, BERT).
  • Fine Tuning-Adjusting a pre-trained AI model for specific tasks (e.g., fine-tuning GPT for medical chatbot responses).
  • Text-to-Image Models-AI that generates images from text prompts (e.g., DALL·E, Stable Diffusion).
  • Text-to-Video Models-AI that creates videos from text descriptions (e.g., Runway ML, Sora by OpenAI).
  • Text-to-Speech (TTS)-AI that converts written text into realistic speech (e.g., ElevenLabs, Google Text-to-Speech).
  • Diffusion Models- AI techniques that gradually refine random noise into detailed images (used in DALL·E, Stable Diffusion).
  • Prompt Engineering-The art of crafting better inputs to guide AI models to generate desired results.
  • AI Hallucination-When an AI generates incorrect, misleading, or unrealistic content.
  • AI Music Generation-AI composing new songs based on trained music patterns (e.g., Jukebox, Amper Music).
  • AI Code Generation-AI writing or suggesting code (e.g., GitHub Copilot, Code Llama).
